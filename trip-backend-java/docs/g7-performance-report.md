**说明**：
- Java 版本 rate limit 配置：1000 请求/900秒（15分钟）

- **Java 版本的 rate limit 配置更宽松**，允许更高的 QPS
- 这是预期行为，rate limit 保护机制工作正常

**结论**：✅ **登录接口性能达标**
