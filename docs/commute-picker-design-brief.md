# 设计简报：最短通勤择优页面（CommutePicker）

> 用途：粘贴到 WorkBuddy「设计创意」对话，让设计 AI 产出与现有项目风格一致的精修稿。
> 本简报桥接编码对话的上下文，无需你手动复述。

## 1. 产品与项目背景
- 产品名：**trip**（旅行行程规划 Web App）。
- 技术栈：前端 **Vue 3 + Vite + Naive UI + 高德地图 JS API**；后端 FastAPI。
- 设计系统：Naive UI 组件库；主色 accent `#665CA2`（紫）；浅色主题；圆角卡片风格。
- 已有页面参照：**登录页（Login.vue）** 已做成「左侧品牌主导区 + 右侧表单主操作区」的分栏布局，窄屏（≤720px）退化为单列。本页面应与之保持统一气质。

## 2. 功能定义
用户在「当前位置」已知的前提下，面对**多个候选目的地**，希望快速知道「从当前位置出发、通勤时间最短的是哪一个」。
- 出行方式：驾车 / 公交 / 步行 / 骑行（单选）。
- 候选目的地输入：① 地址/名称搜索；② 地图打点；③ 从知识库 POI 选择。
- 计算后：按耗时升序排列，耗时最短者高亮为「推荐」，并展示耗时、距离、换乘次数（公交）、预计到达时刻、一键唤起高德导航。

## 3. 页面结构（建议视觉层级）
1. **页头**：标题「最短通勤择优」+ 一句话说明。
2. **出行方式 / 起点卡片**：出行方式分段选择器；城市输入框（公交必填）；起点定位状态 + 「重新定位 / 在地图选起点」按钮。
3. **候选目的地卡片**：搜索输入框 + 添加按钮；「地图打点加候选 / 从知识库选」入口；候选列表（可删除）。
4. **地图卡片（视觉主角）**：显示起点🚩与各候选标记；**推荐路线以紫色加粗折线绘制**；点击地图可打点。
5. **计算按钮**：主色大按钮，loading 态。
6. **结果列表**：卡片流，推荐项左侧紫色高亮边 + 浅紫底；每行含排名 #、名称、耗时(强)、距离、换乘(公交)、「约 HH:MM 到达」、对比提示「比次优快 X 分钟」、导航按钮。

## 4. 设计交付要求
- 产出：Web App 页面设计稿（桌面 + 移动断点），与现有 Login 页风格统一。
- 重点打磨：地图作为视觉主角时的留白与信息密度；推荐路线的强调方式；结果列表的可扫读性。
- 风格：克制、用途优先、清晰的视觉层级与状态可见（loading / 限流提示 / 空态）。
- 颜色：主色 `#665CA2`，浅色背景，文字 `#2b2d31` / 次级 `#6c6e74`。
