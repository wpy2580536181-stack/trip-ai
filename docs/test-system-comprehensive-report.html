1. 项目概述与测试架构总览

Trip 是一个 AI 智能旅行规划系统，采用三层架构：前端 Vue 3 应用、Node.js (Express 5) 后端（正在向 Python FastAPI 迁移）。由于技术栈横跨三种语言和多个框架，测试体系也分散在不同子项目中，每个子项目的测试成熟度差异显著。

核心发现：测试覆盖存在严重不均衡。trip-backend（Python 后端）拥有最完善的测试体系（642 个测试函数 + 集成测试），而 trip-front（前端）仅有 1 个测试文件，几乎无测试保护。

2. 测试类型详解

2.1 单元测试 (Unit Tests)

单元测试是三个子项目中最广泛使用的测试类型。所有单元测试均采用 纯白盒测试 方法，不涉及外部服务依赖（数据库、Redis、LLM API 等），通过 mock 来隔离被测单元。

trip-front — 零依赖单元测试

前端唯一的测试文件位于 src/api/__tests__/stream-parser.test.mjs，使用 Node.js 内置的 node:test 和 node:assert/strict，无需安装任何第三方测试包。采用 .mjs 扩展名而非 .ts，因为 node:test 原生支持 ES Module。

import { test, describe } from 'node:test'
import assert from 'node:assert/strict'

describe('getBackoffMs', () => {
  test('attempt=1 -> 1s', () => assert.equal(getBackoffMs(1), 1000))
  test('attempt=2 -> 2s', () => assert.equal(getBackoffMs(2), 2000))
  // ...指数退避 1s*2^(n-1)，封顶 16s
})

2.2 集成测试 (Integration Tests)

仅 trip-backend 实现了集成测试。集成测试通过两种方式进行：

  1. HTTP 集成测试：使用 httpx.AsyncClient(transport=ASGITransport(app)) 直接调用 FastAPI 应用实例，无需启动真实服务器。模拟完整 HTTP 请求-响应周期，测试路由、中间件和控制器。
  2. 数据库集成测试：使用 sqlite+aiosqlite:///./test.db 作为测试数据库，通过 SQLAlchemy ORM 执行真实 CRUD 操作。session 级建表，每次测试后 DELETE 清理数据。
关键设计：测试数据库使用 SQLite 文件，无需外部 MySQL 服务。每个测试函数获得独立数据库会话，测试后自动回滚/清理，保障完全隔离。

4. AI Agent 评估框架

Eval 框架是项目中 最独特和有价值的测试基础设施，专门用于评测 LLM Agent 输出质量。它跨 trip-server 和 trip-backend 两个子项目共享同一套设计。

4.1 流水线架构

Step 1: Fixture 加载

从 eval/fixtures/trip-planning/ 加载 YAML 文件，解析输入消息、用户偏好和预期结果。支持按 id 或 tag 筛选。

Step 2: Agent 执行

Mock 模式：使用确定性 Agent 输出，适合测试 evaluator 逻辑本身。
Real 模式：通过 HTTP 调用真实后端 API (/api/trip/chat)，需要后端运行 + eval-test 账号。

Step 3: Evaluator 评分

13 个注册的评分函数并行执行，每个验证一个质量维度。支持多采样投票 (--samples N)，取多数结果降低 LLM 波动影响。

Step 4: 报告生成

JSON 格式报告，包含按 tag、evaluator 分组的通过率统计和 token 使用详情。

8. 总体评价与改进建议

8.1 优势

  • Python 后端测试完善：trip-backend 拥有 642+ 测试函数，覆盖控制器、服务、Agent、中间件等所有核心模块，且实现了 HTTP 和数据库双重集成测试
  • Eval 框架创新：13 个 Evaluator + 10 个 YAML Fixture 的 Agent 评估体系在 AI 项目中极具价值，覆盖了行程规划领域的各个质量维度
  • Mock 模式成熟：trip-backend 的 conftest.py 提供了丰富的 fixture 体系（数据库、客户端、LLM、Redis 均有测试替身），测试隔离保障完善
  • 性能测试有体系：trip-server 拥有 8+ 个自动化基准测试脚本和完整的测试结果数据（含可视化图表）
